# Troubleshooting — Phantom Blade Zero trainer

Download: [moggydaytrainer.com/f/phantom-blade-0-trainer](https://moggydaytrainer.com/f/phantom-blade-0-trainer)

## Qi resets after death

Enable **Keep currency on death** (`Shift+F1` per MoggyDay list). Without it, Qi and related values may roll back after dying.

## Trainer does not detect the game

1. Load into gameplay (not only menus).
2. Retry **Play** in TrainerHub after 15–20 seconds.
3. Run TrainerHub **as administrator**.
4. Disable overlays temporarily.

## After a game patch

Update Phantom Blade Zero in Steam, then check MoggyDay for trainer **v1.0.0+**.

## Antivirus / install path

Whitelist the TrainerHub folder. Do not install under `Program Files`.

## Online modes

MoggyDay supports **solo / offline / custom** — not competitive online.
